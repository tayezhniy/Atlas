# Тестовые фикстуры для Atlas

Эталонные проекты для интеграционных тестов индексатора (раздел 11.4 ТЗ).

Структура:
- `small/` — проект до 100 файлов (для замера на малом проекте)
- `medium/` — проект 500–2000 файлов (для замера на среднем проекте)
- `large/` — проект более 5000 файлов (для замера на большом проекте)

Каждый фикстура должен содержать:
- Исходный код на поддерживаемых языках (TypeScript, Python, Rust, Go)
- Markdown-файлы (README, документация)
- Тесты
- Git-репозиторий с историей коммитов
