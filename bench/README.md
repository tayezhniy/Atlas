# Сценарии замера производительности и экономии токенов

Сценарии, фиксированные наборы задач и скрипты прогона лежат в этом каталоге и воспроизводимы (раздел 14.1 ТЗ).

## Методика замера (раздел 14.1)

1. 3 проекта: малый (до 100 файлов), средний (500–2000), большой (более 5000)
2. 15–20 реальных задач на каждый проект
3. Два режима: без Atlas и с Atlas
4. Фиксируются: суммарные токены, число вызовов, время, правильность результата

## Скрипты

- `measure.sh` — базовый скрипт замера токенов
- `compare.sh` — сравнение с и без Atlas
- `report.py` — генерация отчёта о замерах
